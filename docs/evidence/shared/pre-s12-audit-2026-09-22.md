## State and schema findings

- New queued attempt: requirement MATCHING, workflow RUNNING/QUEUED.
- Valid recommendation: requirement MATCH_FOUND, workflow PENDING_APPROVAL, offer PENDING, transaction PENDING_APPROVAL, no reservation.
- Approval: request/workflow/transaction APPROVED, offer ACCEPTED, reservation ACTIVE.
- Rejection: request/workflow/transaction REJECTED, offer REJECTED, no reservation.
- Revision: workflow/offer REVISION_REQUESTED, prior pending transaction REJECTED (the existing transaction enum has no revision value), request OPEN, no reservation. The note remains on workflow/approval and is returned in requirement detail.
- Failure: workflow FAILED (or business REVISION_REQUESTED), request OPEN, no automatic reservation. Buyer can explicitly retry.
- Completion: request/workflow/transaction COMPLETED; reservation CONFIRMED. ReservedQuantity continues to account for committed/transferred inventory, so it is not made available for a second sale.

All eleven migrations are now applied there. EF reports no model drift. Test fixtures also verify migration from clean and legacy schemas, normalized roles, FKs, uniqueness, checks and PostgreSQL concurrency.
