# Seller Guide

## Overview
Sellers use SurplusLink to list excess or leftover construction inventory, tools, and machinery for resale to buyers across Sri Lanka.

## Creating a Listing
Sellers select a catalog template or category and specify:
1. **Item Name & Category**: Select from the item catalog (e.g. Paint, Cement, Timber, Rebar, Generator).
2. **Selling Format / Quantity Mode**:
   - **PACKAGE**: Sold in containers (e.g., 4L Cans, 50kg Bags, Cartridges, Boxes).
   - **PIECE**: Sold individually (e.g., Tools, Generators, Compressors, Fixtures).
   - **CONTINUOUS_BULK**: Sold by measurement (e.g., River Sand, Aggregates, Bulk liquids).
3. **Quantity & Pricing**:
   - For package mode: Specify package container type (e.g. Can), package size (e.g. 4L), package count (e.g. 3 cans), and unit price per package container.
   - Total volume/quantity is automatically calculated (e.g., 3 cans × 4L = 12L total).
4. **Item Condition**: New, Excellent, Good, Fair, or Poor.
5. **Location & Availability**: Storage address/city and available until date.
6. **Custom Attributes**: Specific properties defined in the catalog template (e.g., Colour, Thickness, Power Rating).

## Listing Verification
- Manager approves new seller listings before they become active on the public buyer marketplace.

## Fulfilling Offers & Handover
- When a buyer's requirement is matched and approved, an offer is issued to the seller.
- Once accepted, the stock is reserved.
- The seller prepares materials for pickup or dispatch, updates handover status in the mobile app, and provides OTP / receipt verification to the buyer.
